# 🌐 Projeto de Topologia de Rede Hierárquica

Projeto prático desenvolvido no âmbito do programa **Mulher Digital da Junior Achievement (JA)**, com foco na aplicação de conceitos fundamentais de redes de computadores.

## 📖 Sobre o Projeto

Este projeto consiste na criação de uma **topologia de rede hierárquica**, seguindo o modelo de três camadas amplamente utilizado em ambientes corporativos:

- **Camada de Núcleo (Core Layer):** responsável pelo tráfego de alta velocidade entre os principais dispositivos da rede, garantindo desempenho e redundância.
- **Camada de Distribuição (Distribution Layer):** atua como intermediária entre o núcleo e o acesso, aplicando políticas de roteamento, segmentação e controle de tráfego.
- **Camada de Acesso (Access Layer):** ponto de conexão direta dos dispositivos finais (computadores, notebooks, etc.) à rede.

Além da construção da topologia, foi realizado o **endereçamento IP** de todos os dispositivos, garantindo comunicação correta entre os diferentes segmentos da rede.

## 🎯 Objetivos

- Compreender e aplicar o modelo hierárquico de redes (Núcleo, Distribuição e Acesso).
- Praticar o planejamento e a configuração de endereçamento IP.
- Validar a conectividade da rede utilizando protocolos de diagnóstico.
- Consolidar conhecimentos teóricos por meio de uma atividade prática guiada pelo programa Mulher Digital da JA.

## 🛠️ Tecnologias e Ferramentas Utilizadas

- Simulador de redes (ex: Cisco Packet Tracer)
- Protocolo **ICMP** (testes de ping)
- Protocolo **ARP** (resolução de endereços MAC)
- Endereçamento IP (IPv4)

## ✅ Testes Realizados

Para validar o funcionamento da topologia, foram realizados os seguintes testes, documentados em vídeo:

- **Testes ICMP:** verificação da comunicação fim a fim entre os dispositivos através de comandos de ping.
- **Testes ARP:** análise da resolução de endereços MAC a partir dos endereços IP na rede local.
